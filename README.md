# Balaji Loan & Insurance Services

A modern, responsive financial and insurance advisory web application tailored for Madurai and Tamil Nadu customers. Built with **React 19**, **Vite**, **Framer Motion**, and **Lucide React**.

## 🌟 Key Features

- **Comprehensive Loan Advisory**:
  - Home Loans & Property Finance
  - Mortgage / Loan Against Property (LAP)
  - Business & MSME Loans
  - Machinery & Equipment Financing
  - Working Capital Solutions (CC / OD limits)
  - Personal Loans & Vehicle Loans
  - Education & Agricultural Financing
- **Insurance Solutions**:
  - Health & Medical Insurance
  - Motor / Vehicle Insurance
  - SME & Commercial Insurance
  - Travel Insurance
  - Home & Property Insurance
- **Interactive Tools & Resources**:
  - EMI Loan Calculator
  - Eligibility & Document Checklists
  - Financial FAQs & Advisory Guides
  - Direct WhatsApp & Call Inquiries
- **Modern Responsive Design**:
  - Built with custom CSS design system
  - Fluid mobile navigation and responsive layouts
  - Micro-interactions powered by Framer Motion

## 🛠️ Tech Stack

- **Frontend**: React 19, React Router DOM v7
- **Styling**: Vanilla CSS (modular design system)
- **Icons**: Lucide React
- **Animations**: Framer Motion
- **Build Tool**: Vite

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18 or later recommended) installed.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/saran531/loan.git
   cd loan
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

5. Preview production build:
   ```bash
   npm run preview
   ```
